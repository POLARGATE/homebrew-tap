# Homebrew de Polargate

Apps de Mac de [Polargate](https://polargate.ai) que se instalan con Homebrew.

```sh
brew install polargate/tap/polarbat
```

| App | Qué hace | Web |
|---|---|---|
| PolarBat | App de barra de menús que mantiene el Mac despierto, también con la tapa cerrada | [polarbat.com](https://polarbat.com) |

Las apps se actualizan solas. Para quitar una con sus datos: `brew uninstall --zap polarbat`.
